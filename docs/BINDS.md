# RaidPad — Button Map

Xbox One controller · SPT 4.1.6 · v0.7.2

`P` = set priority (higher wins) · **hold** / **double** = secondary binding

## Base layout — raid, no shoulder held

| Input | Action |
| --- | --- |
| LT | aim (hold) |
| RT | fire (hold) |
| A | jump |
| B | crouch · **hold** prone |
| X | reload · **hold** check ammo · **double** quick reload |
| Y | quick-select weapon · **hold** inspect |
| LS | sprint |
| RS | knife kick · **hold** select knife |
| D-Pad ↑ | tactical device · **hold** toggle |
| D-Pad ↓ | fire mode · **hold** check · **double** force auto |
| D-Pad ← | scope magnification · **hold** change scope |
| D-Pad → | change scope |
| BACK | inventory |
| START | map overlay |
